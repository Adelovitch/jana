Question à deux réponses : vrai ou faux.

Vrai

Deux pièges classiques

  • Un code postal contient des chiffres, mais c'est un code. On peut le stocker comme du texte (A).
  • Un numéro d'adhérent composé uniquement de chiffres peut être classé N dans cet exercice. Dans une vraie base, un identifiant peut aussi être stocké comme du texte.
Et l'identifiant ?

Il sert à distinguer deux éléments, même s'ils se ressemblent. Deux livres peuvent avoir le même titre, mais chacun peut avoir un numéro unique.
